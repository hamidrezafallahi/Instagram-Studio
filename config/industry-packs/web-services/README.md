# خدمات طراحی و برنامه‌نویسی
ورودی ضروری: خدمات فروشگاهی/آموزشگاهی/شرکتی/برندینگ، stackهای واقعی، فرایند، نمونه‌کار با اجازه، محدودهٔ قیمت/زمان و نحوهٔ جلسه.
ستون‌ها: حل مسئلهٔ مشتری، قبل/بعد واقعی، فرایند اجرای پروژه، اشتباه‌های رایج، case study و معرفی خدمت.
CTA: درخواست بررسی سایت، رزرو جلسه یا تکمیل brief پروژه.
FAQ: هزینه وابسته به دامنه، پشتیبانی، مالکیت کد، زمان و مراحل؛ تعهد قراردادی خارج دانش به مالک ارجاع شود.
KPI: سرنخ واجد شرایط، جلسه، پیشنهاد قیمت و قرارداد؛ ترافیک فنی صرف معیار موفقیت نیست.
پذیرش: یک پست خدماتی و یک case-study پیش‌نویس بدون ساخت نمونه‌کار یا عدد نتیجهٔ جعلی.
