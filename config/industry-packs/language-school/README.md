# آموزشگاه زبان
ورودی ضروری: انگلیسی/آلمانی/فرانسوی/ایتالیایی، سطح‌ها، تقویم دوره، مدرس‌های تأییدشده، شهریه، ظرفیت، شیوهٔ آنلاین و لینک ثبت‌نام.
ستون‌ها: نکتهٔ آموزشی، تمرین کوتاه، معرفی دوره، روش مطالعه، معرفی مدرس و تجربهٔ واقعی زبان‌آموز با رضایت.
هر زبان با مدرس/منبع معتبر بازبینی؛ تولید هم‌زمان چهار زبان هزینه و زمان جدا دارد.
LMS connector فقط catalog عمومی دوره و لینک enrollment لازم را بخواند؛ نمره، صدای کلاس و اطلاعات دانش‌آموز وارد تولید محتوا نشود مگر مجوز صریح.
CTA: تعیین سطح، جلسهٔ معرفی یا ثبت‌نام. قول نمره/مهاجرت/یادگیری تضمینی نسازید.
KPI: درخواست تعیین سطح، ثبت‌نام واجد شرایط و تکمیل خرید.
پذیرش: برنامهٔ یک دورهٔ آنلاین با تاریخ واقعی و لینک صحیح، بدون دسترسی غیرضروری به اطلاعات دانشجویان.
