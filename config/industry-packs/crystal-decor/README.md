# ظروف کریستال و دکوری
ورودی ضروری: SKU، جنس/ابعاد/رنگ دقیق، قیمت/موجودی، عکس واقعی، بسته‌بندی، ارسال، مرجوعی و مراقبت.
ستون‌ها: چیدمان، معرفی محصول، هدیه، مقایسهٔ واقعی، نگهداری و بسته‌بندی.
تولید تصویر می‌تواند پس‌زمینه را طراحی کند؛ شکل/رنگ/ابعاد محصول واقعی نباید بدون برچسب تصویری تغییر کند.
CTA: مشاهدهٔ محصول، انتخاب هدیه یا سؤال دربارهٔ موجودی. پاسخ ارسال و مرجوعی فقط از سیاست مصوب.
KPI: کلیک محصول، پیام خرید واجد شرایط، سفارش و ارزش خرید با attribution.
پذیرش: محتوای هر SKU با عکس و موجودی همان SKU؛ پیشنهاد کالای ناموجود بدون اطلاع ممنوع.
