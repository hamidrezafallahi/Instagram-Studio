# بسته‌های صنعت
چهار بستهٔ زیر نمونه‌های خواسته‌شدهٔ مالک‌اند، نه اطلاعات قطعی کسب‌وکارهای واقعی.
هر pack schema مشترک دارد: required_fields، content_pillars، claims_policy، FAQ_fields، CTA_types، KPI و freshness_rules.
packها دانش محرمانه یا credential ندارند. brand instance مستقل از template است؛ ویرایش یک برند قالب دیگران را تغییر نمی‌دهد.
پذیرش: اضافه‌کردن یک صنعت دیگر فقط با دادهٔ pack و migration لازمِ schema، نه تغییر workflow.
