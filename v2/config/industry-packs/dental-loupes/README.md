# فروش لوپ دندان‌پزشکی Luca Loupe
ورودی ضروری: کاتالوگ رسمی، مدل/SKU، مشخصات دقیق، تصاویر مجاز، موجودی، قیمت معتبر، ضمانت، خدمات و راه تماس.
ستون‌ها: معرفی مدل، راهنمای انتخاب مبتنی بر مشخصات تأییدشده، آموزش استفادهٔ سازنده، نگهداری و سؤال‌های خرید.
هیچ عدد بزرگ‌نمایی، وزن، گواهی یا ادعای درمانی بدون سند ساخته نشود. نام برند ارائه‌شده توسط مالک است؛ اصالت/نمایندگی فرض نشده.
CTA: مشاورهٔ انتخاب محصول، درخواست مشخصات یا استعلام موجودی.
پاسخ به نیاز بالینی یا ادعای کاهش آسیب/بهبود درمان برای بازبینی متخصص/مالک ارجاع شود؛ این pack توصیهٔ پزشکی تولید نمی‌کند.
قیمت/موجودی freshness کوتاه و قابل تنظیم؛ stale باعث استعلام، نه پیشنهاد قطعی فروش.
پذیرش: توضیح محصول فقط از SKU و منبع همان مدل؛ عدم ترکیب مشخصات مدل دیگر.
