# داشبورد فارسی
## صفحات و رفتار
- انتخاب‌گر برند دائمی؛ نمای کل مالک فقط aggregate مجاز، با فیلتر و نام برند واضح. ایجاد/ویرایش/آرشیو برند و انتخاب صنعت بدون تغییر کد.
- هزینه و درخواست‌ها: سهمیهٔ رایگان مشترک، مصرف هر برند، درخواست شارژ/پرداخت، جایگزین رایگان، وضعیت رسید و ادامهٔ کار پس از بررسی.
- خانه: وضعیت اجرا، کار بعدی، کارهای منتظر تأیید، هزینهٔ دوره، اتصال خراب و سرنخ‌های جدید.
- راه‌اندازی برند: فرم چندمرحله‌ای با ذخیرهٔ خودکار؛ اطلاعات ضروری از اختیاری جدا.
- اتصال‌ها: کارت هر حساب، نوع auth، scopes، تاریخ انقضا، دکمهٔ تست، قطع/تعویض و فهرست capability واقعی.
- تقویم: هفته/ماه، زمان محلی، فیلتر کانال، drag/drop با ابطال approval آیتم تغییرکرده.
- استودیو: brief، نسخه‌های متن و رسانه، منابع، CTA، پیش‌نمایش پلتفرم، مقایسهٔ نسخه و QA.
- تأییدها: نمایش نسخه، مقصد، زمان و هزینه؛ قبول/رد/درخواست اصلاح.
- صندوق پیام: گفتگو، پاسخ پیشنهادی، پنجرهٔ مجاز پاسخ، handoff و وضعیت اپراتور.
- رشد و مشتری: فرصت تعامل دستی، مرحلهٔ lead، یادآوری پیگیری و نتیجهٔ قرارداد.
- سایت و سئو: inventory، مسائل اولویت‌دار، diff تغییر و rollback.
- تبلیغات: پیشنهاد، بستهٔ خلاقه، بودجه، هزینهٔ واقعی و نتیجه.
- گزارش: تاریخ/کانال، دادهٔ ناقص، export و منابع سنجه.
- مکالمه: درخواست مالک، attachments، کارت plan/action و جریان پیشرفت؛ ارسال متن به معنی اجرای بی‌قید نیست.
- تنظیمات: اختیار، مدل، timezone، بودجه، نگهداری، کاربران و توقف اضطراری.

## دکمهٔ اجرا
گزینه‌های «ساخت برنامه»، «تولید پیش‌نویس»، «اجرای موارد مجاز»؛ پیش از شروع خلاصهٔ محدوده و سقف هزینه.
یک کلیک command با idempotency key می‌سازد و run_id برمی‌گرداند. دوبار کلیک run دوم نسازد.
run_state با content_state جداست؛ waiting_for_approval شکست نیست.
«توقف» کار جدید را متوقف می‌کند و وضعیت عملیات درحال ارسال را نمایش می‌دهد؛ وعدهٔ برگرداندن پیام ارسال‌شده ندهد.

## کیفیت و پذیرش
RTL واقعی، متن انگلیسی/URL با جهت درست، تقویم شمسی اختیاری، navigation کیبورد، کنتراست، responsive.
loading، empty، error، disconnected و partial-data طراحی شوند. دکمهٔ disabled دلیل و راه رفع داشته باشد.
هیچ عدد نمودار sample به‌عنوان واقعی نمایش داده نشود؛ token و password بعد از ذخیره بازنمایی نشوند.
