# ویرگول و بازنشر
وظیفه: تهیهٔ مقالهٔ متناسب با مخاطب ویرگول، عنوان، خلاصه، تصویر و لینک ارجاع طبیعی به سایت.
API عمومی انتشار ویرگول در این بررسی اثبات نشده؛ manual export پیش‌فرض با HTML/Markdown پاک و دارایی.
برای بازنشر، سیاست original/canonical را بررسی کنید؛ اگر canonical قابل تنظیم نیست، نسخهٔ بازنویسی‌شدهٔ ارزشمند و لینک منبع، نه انتشار انبوه نسخهٔ یکسان.
receipt شامل URL، زمان و شخص منتشرکننده؛ verification با دسترسی مجاز، در نبود آن owner_reported.
ساخت بک‌لینک انبوه یا پست بی‌ربط جزو workflow نیست. درخواست outreach از طرف مالک به approval پیام مستقل نیاز دارد.
پذیرش: بستهٔ دستی قابل کپی، منبع اصلی مشخص و گزارش «آمادهٔ انتشار» از «منتشرشده» جدا.
منبع S18 برای وضعیت دسترسی و S19 برای اصول جست‌وجو.
