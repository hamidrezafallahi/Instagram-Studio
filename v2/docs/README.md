# مستندات محصول
این پوشه مرجع مشترک مالک، توسعه‌دهنده و بهره‌بردار است.
- product: نیازها، فرض‌ها و پوشش قابلیت‌ها.
- architecture: مرز ماژول‌ها، تصمیم‌ها و جریان‌ها.
- implementation: ترتیب ساخت، پیشرفت و معیار عبور.
- user-guide: کار روزانه و اتصال حساب‌ها.
- operations: استقرار، خرابی، بازیابی و هزینه.
- research: شواهد و محدودیت‌های پلتفرم‌ها.
هر تغییر قرارداد باید همراه سند، آزمون و یادداشت مهاجرت باشد. مستندات فارسی، نام مسیرها انگلیسی، تاریخ ذخیره‌شده میلادی/UTC و نمایش فارسی قابل انتخاب باشد.
پذیرش: یک فرد غیرتوسعه‌دهنده بتواند با راهنمای استفاده برند ایجاد کند، پیش‌نویس ببیند و انتشار را متوقف کند.
