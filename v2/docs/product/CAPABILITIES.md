# ماتریس قابلیت و مسیر جایگزین
وضعیت جدول «هدف طراحی» است؛ account_verified برای همه هنوز false است. بدون تست واقعی علامت سبز اتصال نگذارید.
| قابلیت | مسیر هدف | شرط | جایگزین |
|---|---|---|---|
| پست/کاروسل/ریلز IG | مستقیم رسمی یا route اختیاری | حساب و مجوز/مدیا معتبر | فایل+متن دستی |
| Story IG | capability جدا per account | روش ورود/قابلیت جاری | بستهٔ استوری |
| Trial Reel | فقط پس از اثبات endpoint و حساب | در این بررسی اثبات نشده | راهنمای تریال دستی |
| پاسخ کامنت رسانهٔ خود IG | رسمی/واسط مجاز | scope و هدف مجاز | draft پاسخ |
| کامنت پست دلخواه دیگران | اثبات موردی لازم | عمومی فرض نشود | فرصت+draft+ارسال مالک |
| دایرکت IG | رسمی/واسط | پنجره/مجوز/رضایت جاری | handoff |
| پست LinkedIn | رسمی/واسط | شخصی/سازمانی و scope | متن/مدیا دستی |
| پیام و دعوت LinkedIn | پیش‌فرض manual | دسترسی عمومی فرض نشود | پاسخ پیشنهادی/یادآوری |
| Telegram مالک | Bot API | pair و token | dashboard |
| WhatsApp مالک | Business Platform | account/window/cost | Telegram/dashboard |
| مقاله سایت | CMS adapter | auth و قابلیت نوشتن | فایل و task مالک |
| SEO فنی | ChangeSet و adapter | دسترسی، preview، backup | developer task |
| Canva Autofill | اختیاری | plan/scope | قالب محلی |
| Zernio | اختیاری | quota/account/action | مستقیم یا manual |
| Postiz | اختیاری self-host | نصب/API/license/provider | مستقیم یا manual |
| تپسل/یکتانت | export، سپس adapter اثبات‌شده | API مدیریت و بودجه | پنل مالک |
| ویرگول | export در نسخهٔ پایه | API عمومی اثبات نشده | انتشار مالک |
| تولید AI بدون هزینهٔ API | مدل محلی/هارنس دستی | کیفیت و دسترس‌بودن | قالب/ویرایش انسانی |

verified به معنای امکان ارسال بی‌اجازه نیست؛ Policy و Billing مستقل‌اند.
