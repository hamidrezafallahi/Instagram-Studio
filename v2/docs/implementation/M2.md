## جریان
1. مالک «درخواست انتشار» می‌زند → قصد با کلید یکتایی، hash نسخهٔ جاری و نسخهٔ سیاست ثبت می‌شود.
   - برند متوقف/آرشیو یا `draft_only` → رد (POLICY_DENIED) و ثبت در audit.
   - قابلیت قابل استفاده نیست → `manual_required` و بستهٔ دستی (ADR-007).
   - `review_required` یا نبود قاعدهٔ خودکار → `awaiting_approval`.
   - هزینه با `free_only` → `awaiting_funds` و FundingRequest.
2. تأیید انسانی (فقط owner/reviewer کاربر انسانی) با همان payload_hash → `authorized` و رویداد outbox در همان تراکنش.
3. worker: outbox → job؛ claim با lease؛ بررسی دوبارهٔ توقف، مهلت، hash، سیاست، تأیید، قابلیت و بودجه؛ commit `executing` **پیش از** تماس بیرونی؛ ارسال با کلید پایدار؛ ثبت نتیجه.
4. پاسخ نامعلوم یا crash پس از ارسال → reconcile با `getOperationStatus`؛ هرگز ارسال کور. اثبات عدم ثبت → ارسال دوباره با همان کلید؛ نبود اثبات پس از سقف تلاش → بررسی دستی.

## آزمون پذیرش
- `pnpm typecheck` → بدون خطا. `pnpm build` (داشبورد) → موفق، ۱۷ مسیر.
- `node scripts/run-tests.ts --evidence docs/implementation/evidence/M2/full-run.txt` → **۱۶۸ از ۱۶۸ موفق، صفر skip**.
- فایل اختصاصی: `tests/acceptance/m2-execution.test.ts` (۱۳ آزمون):
  A03 دوبار کلیک هم‌زمان، دو worker هم‌زمان، A04 ویرایش پس از تأیید، A05 crash پس از پاسخ ارائه‌دهنده (یک انتشار، تأیید reconciled)، پاسخ نامعلوم و رد retry، A15 توقف و ادامه، A14 موعد گذشته و زمان‌بندی دوباره با تأیید تازه، A12 مسیر دستی و ثبت owner_reported، A09 سهمیهٔ تمام‌شده → درخواست شارژ، backoff برای RATE_LIMITED، A10 رزرو هم‌زمان بودجه بدون عبور از سقف.
- اجرای واقعی `node apps/worker/src/main.ts` روی پایگاه دادهٔ محلی پس از `db:migrate` بدون خطا شروع شد.

## محدودیت‌ها
- هیچ adapter واقعی (Instagram، LinkedIn، …) وجود ندارد؛ M5 به حساب و مجوز پلتفرم نیاز دارد.
- قاعده‌های `auto_scoped` در API تنظیمات هنوز قابل ویرایش نیستند (فقط حالت و توقف)؛ موتور سیاست آن‌ها را پشتیبانی می‌کند.
- تعریف سقف بودجه فقط از لایهٔ مخزن ممکن است؛ UI بودجه همراه دفتر هزینه در M7 ساخته می‌شود. چون همهٔ مسیرهای فعلی رایگان‌اند، رزرو بودجه فقط با آزمون مستقیم سنجیده شد.
- اجراهای داخلی (برنامهٔ هفته، پیش‌نویس، سنجه) همچنان درون‌فرایندی‌اند (ADR-022 به‌روز شد)؛ فقط side effect بیرونی از worker عبور می‌کند.
- بازبینی مرورگری صفحهٔ تازه انجام نشد؛ فقط build و typecheck.
