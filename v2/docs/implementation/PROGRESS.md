# وضعیت ساخت
وضعیت اولیه: فقط معماری تحویل شده؛ هیچ مرحلهٔ نرم‌افزاری اجرا نشده است.
| مرحله | وضعیت | شواهد | مانع |
|---|---|---|---|
| M0 تا M8 | not_started | ندارد | اجرا با Claude یا سازندهٔ منتخب آغاز نشده |

سازنده ردیف‌ها را تفکیک کند؛ ستون تاریخ، commit، آزمون، محیط و artifact را اضافه کند.
وضعیت‌ها: not_started / in_progress / blocked_external / passed / failed.
آزمون ساختگی با محیط fake ثبت شود و با آزمون integration واقعی اشتباه نشود.
