# موتور سئوی تخصصی
## مراحل
۱. کشف سایت و inventory با crawl محدود دامنه، robots و rate limit؛ sitemap و canonicalها ثبت.
۲. baseline از Search Console مجاز، performance و analytics؛ دادهٔ unavailable جدا.
۳. technical audit: status، redirect chain، broken links، duplicate canonical، indexability، sitemap، hreflang در سایت چندزبانه، structured data، mobile/performance و internal linking.
۴. intent و موضوع: service/product/category/course/topic، خوشهٔ موضوعی، cannibalization، اولویت بر اساس ارزش کسب‌وکار و شواهد.
۵. brief: سؤال مخاطب، ساختار، اطلاعات دست‌اول مالک، منبع، CTA، لینک‌های داخلی و schema مناسب واقعیت.
۶. اصلاح یا تولید → preview → ChangeSet → approval → staging → production مجاز → verify → پایش.
## سطح اقدام
محتوایی: عنوان، متن، alt و لینک داخلی با scope انتشار.
فنی: robots/noindex/canonical/redirect/template/schema/site config با preview و rollback و اختیار جدا.
تغییر کد/سرور سایت خارج دسترسی CMS به developer task تبدیل شود؛ کامل‌شدن audit معادل اجرای اصلاح نیست.
Product/Offer/Course/Organization structured data فقط با دادهٔ واقعی و ویژگی‌های پشتیبانی‌شده؛ review جعلی یا نمره ساختگی ممنوع.
PageSpeed آزمایشگاهی از دادهٔ واقعی کاربران جدا؛ بهبود امتیاز مساوی رتبهٔ تضمینی نیست.
بک‌لینک: دارایی ارزشمند، معرفی حرفه‌ای، همکاری و PR واقعی؛ خرید لینک با هدف دست‌کاری رتبه و ساخت خودکار انبوه اجرا نشود.
Search Console برای inspection/analytics طبق قابلیت؛ endpoint عمومی برای ایندکس تضمینی همهٔ مقاله‌ها فرض نشود.
پذیرش: audit با finding، evidence URL، severity، effort، owner و verification؛ تغییر نمونه در staging قابل بازگردانی باشد.
