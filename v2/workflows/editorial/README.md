# برنامهٔ تحریریه و رشد
نسخهٔ اولیهٔ برنامه پیشنهادی است، قابل تغییر برای هر برند و ظرفیت واقعی.
| روز | تولید/انتشار پیشنهادی | اقدام ارتباطی و سنجش |
|---|---|---|
| شنبه | یک موضوع اصلی هفته، مقالهٔ پایه، استوری سؤال | بررسی سؤال‌های مشتری و منابع |
| یکشنبه | ریلز آموزشی کوتاه + نسخهٔ متنی لینکدین | پاسخ پیام‌های مجاز و ثبت lead |
| دوشنبه | کاروسل راهنما + استوری پشت‌صحنه | فرصت‌های کامنت مرتبط و دستی |
| سه‌شنبه | تکمیل/انتشار مقالهٔ سایت | لینک داخلی و بررسی landing |
| چهارشنبه | نمونه‌کار/محصول/کلاس با CTA + لینکدین | پیگیری سرنخ با رضایت و مجوز |
| پنجشنبه | ریلز دوم یا بستهٔ تریال آزمایشی | مقایسهٔ hook و نگهداشت |
| جمعه | گزارش و استوری سبک در صورت نیاز | پیشنهاد برنامهٔ هفتهٔ بعد |

این جدول الزام تعداد انتشار برای همه نیست؛ planner متناسب با دارایی، خدمات و پاسخ مخاطب حجم را کم/زیاد کند.
تقویم هر زبان/کانال نسخهٔ مستقل و موعد دارد؛ بازنشر باید برای مخاطب همان کانال بازنویسی شود.
آزمایش رشد: یک متغیر (hook/کاور/CTA/زمان)، فرضیه، baseline، حداقل مشاهده و معیار تصمیم. نتیجهٔ کم‌نمونه «نامطمئن» ثبت شود.
تمرکز بر سری محتوایی، پاسخ سؤال واقعی، زیرنویس، کاور خوانا، نمایش نمونهٔ معتبر، همکاری واقعی و مسیر سادهٔ درخواست خدمت.
خرید ویو/فالوور، engagement pod و ادعای تضمین الگوریتم وارد موتور رشد نشود.
پذیرش: یک هفته برای دو برند متفاوت بدون اختلاط لحن/حساب/بودجه ایجاد شود.
