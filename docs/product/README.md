# مشخصات محصول
## مسئله و کاربران
هدف تبدیل تخصص مالک به محتوای منظم و مشتری قابل پیگیری است. KPI اصلی: سرنخ واجد شرایط، جلسه و قرارداد؛ بازدید شاخص میانی است.
نقش‌ها: owner (اختیار و اتصال)، editor (تولید و ویرایش)، reviewer (تأیید محتوای مجاز)، viewer (گزارش)، service (کارگر با دامنهٔ محدود). نسخهٔ اول یک owner دارد؛ مدل مجوز برای گسترش آماده باشد.

## نیازها
R01 برند: خدمات، مخاطب، لحن، زبان، تمایز، نمونه‌کار، قیمت‌های معتبر، ادعاهای ممنوع و دارایی‌ها.
R02 تقویم روزانه/هفتگی قابل ویرایش با ظرفیت تولید، تعطیلات و timezone.
R03 اینستاگرام: متن، پست، کاروسل، استوری، ریلز، بستهٔ تریال و گزارش.
R04 لینکدین: متن تخصصی، تصویر/سند، تقویم و فرصت‌های ارتباط.
R05 صندوق پیام و پاسخ مبتنی بر دانش تأییدشده با ارجاع موارد مبهم.
R06 تلگرام و واتساپ مالک برای درخواست، رفع ابهام، تأیید و وضعیت.
R07 سایت: کشف CMS، مقاله، رسانه، metadata، لینک داخلی، اصلاحات فنی قابل برگشت.
R08 تبلیغات و توزیع در تپسل، یکتانت و ویرگول همراه بودجه و سنجش.
R09 داشبورد اتصال، اجرا، مکالمه، گزارش، توقف و راهنما.
R10 اجرای کنترل‌پذیر از Claude/Codex/Cursor با MCP و استقلال زمان‌بندی.
R11 Canary اتصال، امن‌سازی اطلاعات ورود، audit و نسخهٔ پشتیبان.
R12 طراحی Canva اختیاری، ابزارهای محلی و route اختیاری Zernio/Postiz.
R13 چند برند پویا از نسخهٔ اول با صنعت/دانش/حساب/تقویم/بودجه مستقل.
R14 حالت free_only و درخواست شارژ/پرداخت مالک برای هر مصرف هزینه‌دار خارج اختیار.

## بیرون از تعهد
دسترسی تضمینی API، ویروسی‌شدن تضمینی، رتبهٔ تضمینی، امکانات پولی رایگان، تقلید فعالیت انسانی برای دورزدن محدودیت، و تولید جعلی تجربه/نظر مشتری.
برای قابلیت غیرقابل اجرا خروجی قابل تحویل دستی تولید شود؛ این «اتصال کامل» محسوب نشود.

## راه‌اندازی
اطلاعات ضروری برای draft: نام برند، خدمت، مخاطب و زبان. برای live: حساب معتبر، سیاست اختیار، منطقه زمانی و حداقل یک پیش‌نمایش تأییدشده.
حذف کانال از برنامه باید فقط آیتم‌های همان کانال را مسدود کند.
