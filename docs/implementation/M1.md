## راهنمای اجرا
```
pnpm install
pnpm db:start
pnpm db:migrate
pnpm dev          # API روی 4310 و داشبورد روی 4300
```
سپس در `http://localhost:4300` مالک را راه‌اندازی کنید و «برندهای نمونه» را بسازید.

## محدودیت‌ها (منتقل به مراحل بعد)
- بازبینی مرورگری همهٔ صفحه‌ها (ویرایش محتوا، اتصال‌ها، تنظیمات) فقط تا حد ساخت برنامه و پیش‌نویس انجام شد؛ بازبینی کامل UI در M8 تکرار می‌شود.
- نمایش ارقام فارسی در همهٔ پیام‌های سرور و نمایش دلیل دکمه‌های غیرفعال به‌عنوان بهبود UI باقی است.
- اجرای run در همان فرایند API بود (ADR-022)؛ در M2 به outbox و worker منتقل شد.
