# فهرست تحویل سازنده
این بسته معماری است و باید به پروژهٔ اجراشونده تبدیل شود.
تحویل نهایی Claude باید شامل موارد زیر باشد:
- source کامل، نسخه‌های قفل‌شده، migration و دادهٔ نمونهٔ چهار برند؛ بدون کلید واقعی.
- دستورهای دقیق setup/start/test/backup/restore برای Windows local و Linux server.
- schemaهای API، تنظیمات و MCP؛ فرم‌های اتصال و قابلیت‌های واقعی اثبات‌شده.
- screenshot/ویدئوی demo از onboarding، تولید، approval، درخواست هزینه و گزارش.
- نتیجهٔ A01 تا A28 با محیط/تاریخ، موارد blocked_external و manual flow.
- گزارش هزینهٔ زیرساخت و مصرف با جداسازی هزینهٔ ثابت، اختیاری و رایگان.
- راهنمای مالک به‌روز؛ فهرست محدودیت‌های باقی‌مانده بدون ادعای تکمیل جعلی.
- شیوهٔ ارتقا، تعویض provider و خروج دادهٔ هر برند.

اولویت تحویل: یک برش واقعی از درخواست مالک تا draft/تأیید/CMS یا کانال مجاز، سپس گسترش. ساخت همهٔ صفحه‌ها بدون اتصال به state و workflow تکمیل محسوب نمی‌شود.
