# خط تولید رسانه
Asset: نوع، منبع، مجوز، consent، brand، checksum، نسخه، dimensions، duration، language و storage_key.
ورودی: لوگو، عکس واقعی محصول، ویدئوی مالک، palette، font مجاز، قالب و brief.
خروجی: تصویر پست/کاروسل، استوری، MP4 ریلز، کاور، زیرنویس SRT/VTT و thumbnail.
Template renderer محلی HTML/SVG به تصویر، FFmpeg برای montage/crop/caption/audio؛ استنتاج تصویر/صدا فقط provider جدا و budget-aware.
ابعاد معمول قالب‌ها قابل تنظیم؛ مشخصات دقیق زمان انتشار از capability خوانده شود. یک فایل برای همهٔ شبکه‌ها به‌زور استفاده نشود.
فونت فارسی embed، نیم‌فاصله، اتصال حروف، جهت اعداد، safe area و بریدگی متن با render visual QA بررسی.
موسیقی/چهره/صدای افراد فقط با مجوز؛ stock و generated برچسب provenance. تصویر محصول نباید مشخصات واقعی را تغییر دهد.
Canva مسیر اختیاری؛ خروجی importشده هم checksum و QA جدید دارد. asset تغییرکرده approval قبلی را باطل کند.
مدیا خصوصی با signed URL؛ عمر URL در زمان upload کافی؛ تمدید بی‌نهایت public ممنوع.
پذیرش: پست فارسی و ریلز نمونه دیده و شنیده شوند؛ متن خوانا، صدا همگام، فایل در مشخصات adapter.
