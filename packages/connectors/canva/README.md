# Canva اختیاری
اتصال REST/MCP مطابق قابلیت حساب و ابزار، نه فرض اشتراک مشترک هارنس.
دریافت template/design، ساخت variant، export و import asset؛ provider jobهای asynchronous track شوند.
Autofill را رایگان فرض نکنید؛ در اسناد بررسی‌شده Canva Free شامل آن نیست. plan و scope در capability ذخیره شود.
اگر محدودیت یا پرداخت: fallback رندر قالب محلی یا بستهٔ متن/دارایی برای ویرایش دستی Canva؛ درخواست پرداخت فقط اگر مالک این مسیر را بخواهد.
APIهای Canva از browser frontend مستقیم با secret تماس نگیرند. output با brand، source_design_id و license ثبت شود.
هیچ وعده‌ای دربارهٔ تولید کامل ریلز با یک endpoint عمومی داده نشود؛ رندر و مونتاژ در media مستقل است.
پذیرش: خروجی local با Canva قطع‌شده همچنان تولید شود؛ فایل export پیش از publish QA شود.
