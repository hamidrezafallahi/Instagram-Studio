# Postiz — گزینهٔ قابل ارزیابی
گزینهٔ self-host برای استفادهٔ مجدد از قابلیت انتشار و تقویم؛ در هسته اجباری نیست. adapter از API آن استفاده کند، نه کپی‌کردن بی‌برنامهٔ کد پروژه.
انتخاب نهایی M0 بر اساس هزینهٔ نگهداری، مجوز نسخه، قابلیت API، اتصال‌های موردنیاز و محدودیت حساب.
اگر فعال شد، استودیو مرجع برنامه و approval است؛ Postiz تنها delivery route. scheduler دوم فقط با قرارداد sync/cancel مشخص.
Self-host بودن هزینهٔ API مدل، تبلیغات، سرور یا مجوز شبکه‌ها را حذف نمی‌کند. نیاز developer app هر provider را در نصب واقعی بررسی کنید.
مخزن بررسی‌شده AGPL-3.0 اعلام کرده؛ سازنده پیش از توزیع/تغییر، الزامات همان نسخه و وابستگی‌ها را بررسی کند.
پذیرش: قطع Postiz به manual_required/degraded منجر شود؛ API key محدود و brand mapping دقیق؛ hidden cloud dependency در حالت free_only نباشد.
