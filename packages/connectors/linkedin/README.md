# LinkedIn
حساب شخصی و صفحهٔ سازمانی در UI جدا؛ destination URN و مجوزهای هرکدام ثبت شود.
ساخت پست متن/تصویر/ویدئو/سند؛ upload رسانه و انتظار پردازش؛ publish و readback مطابق مجوز. API version معتبر در تنظیمات قفل و تاریخ انقضا پایش شود.
network growth: فهرست موضوع/افراد معرفی‌شده توسط مالک، پیشنهاد تعامل مرتبط، draft پیام معرفی و پیگیری دستی. scraping انبوه پروفایل و ارسال خودکار دعوت، قابلیت پیش‌فرض نیست.
DM عمومی خودکار تعهد نشود: سند Messages API دسترسی محدود و عمل صریح عضو را بیان می‌کند؛ Zernio نیز DM لینکدین را پشتیبانی‌نشده اعلام کرده است.
در نبود مجوز پیام، صندوق با import دستی مجاز و reply draft کار می‌کند و «همگام‌سازی خودکار» نشان نمی‌دهد.
کامنت و analytics بسته به route و نوع حساب. دامنهٔ capability Zernio را معادل کل API مستقیم ندانید.
پذیرش: تغییر شخصی به سازمانی نیازمند انتخاب صریح مقصد؛ تلاش DM غیرپشتیبانی‌شده manual_required، نه ارسال پنهان.
