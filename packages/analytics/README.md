# سنجش و گزارش
Snapshot خام provider و metric نرمال جدا؛ هر metric نام، تعریف، واحد، دوره، source، fetched_at و quality دارد.
missing یا unavailable مقدار null است، صفر نیست. reach و views شبکه‌های مختلف هم‌معنا فرض نشوند.
پست: impression/reach، view/retention در صورت دسترسی، save/share، comment، profile visit و link click.
کسب‌وکار: lead، qualified_lead، booking، won/lost، مبلغ قرارداد با ارز؛ منبع attribution و confidence.
UTM با campaign/content_id، landing event dedupe و consent؛ گزارش first-touch/last-touch روشن و attribution نامعلوم جدا.
نسبت‌ها: CTR=click/impression، lead conversion=qualified_lead/attributed_visit؛ اگر مخرج صفر/نامعلوم N/A.
گزارش هفتگی: کار انجام‌شده، تعهدهای عقب‌مانده، عملکرد نسبت به baseline، هزینه، فرصت و پیشنهاد آزمون بعدی.
زمان جمع‌آوری قابل تنظیم؛ dashboard fresh_at نشان دهد؛ API محدود باعث نمایش گمراه‌کننده نشود.
پذیرش: دادهٔ sample، دادهٔ واقعی ناقص و چند ارز جدا نمایش داده شوند؛ CSV/JSON و گزارش خواندنی قابل export.
