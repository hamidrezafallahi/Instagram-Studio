## 4. Differentiators (why Hamidreza)

Each claim must be backed by proof in content. If one is not true in practice, delete it here first. **[confirm all five]**

1. **An engineer, not a template installer.** Custom code where it matters (speed, security, integrations, scale), off-the-shelf tools where they are enough, and the reasons for each choice explained.
2. **Business-first scope.** Every project starts with the business goal (orders, registrations, inquiries) and ends with a way to measure it.
3. **A direct line to the builder.** Clients talk to the person who writes the code. No account-manager relay.
4. **Transparent process and clean handover.** Written scope and milestones. The client owns the domain, hosting, code and admin access. This is a common pain in the Iranian market: domains and hosting registered in the developer's name.
5. **Quality by default.** Mobile-first, fast loading, basic security hardening, search-friendly structure and basic accessibility are part of every build, not upsells.

## 7. Personality

**"The calm senior engineer who explains clearly."**

| Is | Is not |
|---|---|
| Precise: exact terms, real numbers | Hype: superlatives, "magic", "revolution" |
| Confident: says plainly what is and isn't offered | Salesy: pressure, fake scarcity, discount-shop language |
| Generous: gives away real know-how | Arrogant: jargon used to impress |
| Human: first person, real stories, real mistakes | Faceless: an "agency" voice, «تیم متخصص ما» |
| Honest about trade-offs: says when an off-the-shelf tool is enough | One-size-fits-all: "custom" for its own sake |

## 8. Content guardrails

- First person singular («من»). Never pose as an agency. «ما» only for "me and the client" or a named, real collaborator.
- Proof over promises. Every number carries a source and a date, and must exist in `projects/` or `analytics/`.
- Never name or criticise a competitor, or a client's previous developer.
- Client data and screenshots only at the consent level recorded in the project file (`projects/README.md`).
- No political or religious commentary. National occasions (Nowruz, Yalda) briefly and respectfully, tied to business relevance.
- Platform dependence is a legitimate business argument («فروش فقط از دایرکت یعنی وابستگی به یک پلتفرم»). Keep it factual and neutral.
