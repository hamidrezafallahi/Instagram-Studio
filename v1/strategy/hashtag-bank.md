# Hashtag bank

## Rules

- **3–5 hashtags per post**, at the end of the caption, never in the design. Instagram treats hashtags as a minor discovery signal; the hook, the content and saves matter far more.
- Mix: 1–2 core service tags + 1–2 persona tags + 0–1 topic tag.
- Persian tags use «_» for spaces and **never** contain a half-space (it breaks the tag).
- Rotate sets; never paste the same block on every post.
- Before first use, search each tag in the Instagram app: skip tags that are banned, spammy, or mostly unrelated content. Note the check date below.
- `validate_post` (Zernio, free) checks platform limits before scheduling.
